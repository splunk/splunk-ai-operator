# Splunk AI Operator release notes

Release notes are maintained per operator release and should be published with the corresponding
Help version.

Each release should document:

- operator, chart, CRD, and AI service versions;
- supported Kubernetes and Splunk versions;
- new features and changed defaults;
- upgrade and migration requirements;
- deprecated or removed configuration fields;
- security fixes; and
- known issues and workarounds.

Before upgrading, review the release notes and compatibility matrix for both the operator and the
managed AI services.
