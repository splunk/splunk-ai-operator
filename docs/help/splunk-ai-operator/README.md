# Splunk AI Operator

Deploy and manage Splunk AI Platform workloads on Kubernetes with the Splunk AI Operator.

The operator uses Kubernetes custom resources to create and manage AI Platform components,
including AI services, model-serving infrastructure, vector storage, and supporting services.

This guide is for platform administrators and operators who install, configure, secure, and
maintain Splunk AI Platform deployments.

## Get started

1. Review the [Splunk AI Operator overview](overview.md).
2. Confirm the [prerequisites](prerequisites.md), supported versions, and cluster capacity.
3. [Install the Splunk AI Operator](install.md).
4. [Deploy the AI Platform](deploy-platform.md).
5. [Configure AI services](configure-services.md).
6. Verify [Splunk integration](splunk-integration.md) and external access.
