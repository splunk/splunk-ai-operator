```sh

  ./pkg/ai/features/slim ./pkg/ai/features/agentruntime ./pkg/ai -count=1
go vet ./internal/candidatecontract ./cmd/candidate-contract \
  ./pkg/ai/features/slim ./pkg/ai/features/agentruntime

go run ./cmd/candidate-contract --profile cpuOnly
go run ./cmd/candidate-contract --profile fullfeature
go run ./cmd/candidate-contract --profile cpuOnly \
  --manifest config/agent-runtime/testdata/candidate-refresh.yaml \
  --previous config/agent-runtime/candidate-manifest.yaml
go run ./cmd/candidate-contract --profile fullfeature \
  --manifest config/agent-runtime/testdata/candidate-refresh.yaml \
  --previous config/agent-runtime/candidate-manifest.yaml
```

Go 1.26.10 on darwin/arm64. `GOCACHE=/private/tmp/mpr188-go-cache` was used. The focused run recorded 124 passing test/subtest events, zero failures; the CLI package compiled and its behavior was exercised by the four standalone runs. `go vet` passed.

Negative cases include missing/invalid/unqualified image references, invalid YAML, loader conflicts, incompatible prefix/ports/health/schema routes, missing Secret keys, contradictory SLIM bindings, incomplete AITK metadata/routes, unsupported or blocked matrix records, and missing refresh history. Invalid loader values are also omitted from the operator's diagnostics.

## Evidence boundary and remaining work

The renderer simulates schema Job success with an in-memory client. This establishes local configuration and update-path behavior; it does not establish SQL execution, image importability, product invocation, or live rollout health. No cluster, registry, PostgreSQL server, or product endpoint was contacted. Image provenance, owners, architectures, and current registry digests were excluded by the story owner. Matrix entries remain `pending`; current/N-1 certification gates were not run.

Required contract inputs and local acceptance work are complete. Delivery still requires code review and merge. Mirroring/execution remain in MPR-187, schema Job lifecycle in MPR-189, provisioning/integration in the corresponding downstream stories, and final image certification/selection in MPR-216.
